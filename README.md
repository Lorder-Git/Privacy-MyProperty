# Privacy Policy — MyProperty

Informativa sulla privacy per l'app MyProperty, pubblicata tramite GitHub
Pages dalla cartella `docs/`.

Per pubblicarla: Settings → Pages → Source: `Deploy from a branch`,
Branch: `main` / `docs`.

Una volta pubblicata, l'URL sarà del tipo:
`https://<tuo-utente-github>.github.io/Privacy-MyProperty/`
